# C5210-EH(HP) test data

JX金属が公開している `C5210HP_S-S_Curve.xlsx` のうち、`C5210-EH(HP)` の公称応力–公称ひずみデータを、方向別にそのまま抽出したテストデータです。

## ファイル

- `C5210HP_EH_rolling_direction.csv`: 圧延方向、398点
- `C5210HP_EH_transverse_direction.csv`: 圧延直角方向、340点

両ファイルとも列は以下の2列です。

| 列 | 内容 | 単位 |
|---|---|---|
| `engineering_strain` | 公称ひずみ | 小数（無次元） |
| `engineering_stress_mpa` | 公称応力 | MPa |

## アプリでの指定

- 入力形式: `公称応力・公称ひずみ`
- ひずみ単位: `小数 [-]`
- 応力単位: `MPa`

動作確認用の入力例として、初期弾性域の原点通過回帰と0.2%オフセットから算出すると、圧延方向はヤング率 `104316 MPa`、降伏応力 `694 MPa`、圧延直角方向はヤング率 `96863 MPa`、降伏応力 `730.3 MPa` です。これらは元ブックの記載値ではなく、CSV曲線から算出した参考値です。

公称応力が最大となった後はくびれの影響を含むため、真応力–真塑性ひずみへの一様変形換算および硬化則フィッティングでは、目的に応じて上限範囲を調整してください。
