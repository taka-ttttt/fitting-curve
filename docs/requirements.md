# SSカーブフィッティングアプリ 要件定義書

## 1. 文書情報

- 対象: `frontend` に構築する Next.js アプリケーション
- ステータス: 初期実装向け確定要件
- 処理方式: ブラウザ内で完結し、アップロードデータをサーバーへ送信しない

## 2. 目的

金属材料の引張試験データを、CAE解析で利用する真応力–真塑性ひずみカーブへ変換し、Ludwik、Swift、Voceの各硬化則にフィッティングする。自動フィッティング後の手動調整、グラフによる確認、汎用CSVのダウンロードおよびLS-DYNA `*DEFINE_CURVE` 形式のコピーを一連の画面で行えるようにする。

## 3. 対象範囲

### 3.1 対象に含むもの

- 1ファイル、1試験カーブのCSVアップロード
- CSV列の割り当て、単位、ひずみ表現の指定
- 工学応力–工学ひずみから真応力–真塑性ひずみへの変換
- 真応力–真全ひずみから真応力–真塑性ひずみへの変換
- 真応力–真塑性ひずみの直接利用
- Ludwik、Swift、Voce硬化則への自動フィッティング
- グラフ上でのフィッティング範囲調整
- フィッティングパラメータの手動調整
- エクスポート条件を指定したカーブの生成とプレビュー
- 汎用CSVのダウンロード
- LS-DYNA `*MAT_024` の `LCSS` 参照向け `*DEFINE_CURVE` テキストのプレビューとクリップボードへのコピー

### 3.2 初期版の対象外

- 荷重–標点間伸び、荷重–クロスヘッド変位の入力
- ネッキング後の断面積変化を考慮した真応力補正
- 温度依存性、ひずみ速度依存性、異方性、損傷・破断モデル
- 複数試験カーブの平均化や同時フィッティング
- ユーザー認証、サーバー保存、履歴共有
- LS-DYNA材料カード全体の生成および特定材料モデルへの自動接続
- LS-DYNAキーワードファイルのダウンロード

## 4. 用語とデータ定義

| 用語 | 記号 | 定義 |
|---|---:|---|
| 工学応力 | `s` | 初期断面積を基準にした応力 |
| 工学ひずみ | `e` | 初期標点距離を基準にしたひずみ |
| 真応力 | `σ` | 変形中の断面積を基準にした応力 |
| 真全ひずみ | `ε` | 弾性ひずみと塑性ひずみを含む対数ひずみ |
| 真塑性ひずみ | `εp` | 真全ひずみから弾性ひずみを除いた値 |
| SSカーブ | - | 本書では応力–ひずみカーブを指す |

内部計算では応力をMPa、ひずみを無次元量に正規化する。画面入力時には応力単位と、ひずみが無次元量か `%` かをユーザーが選択できるようにする。

## 5. 入力要件

### 5.1 対応するCSVデータ種別

ユーザーはアップロード時に次のいずれかを選択する。

1. 工学応力–工学ひずみ
2. 真応力–真全ひずみ
3. 真応力–真塑性ひずみ

CSVにはヘッダー行を許容し、プレビュー後にX列とY列をユーザーが割り当てる。列名に依存した自動確定は行わず、候補の自動選択に留める。

### 5.2 材料物性

ユーザーは次の値を入力する。

| 項目 | 必須条件 | 用途 |
|---|---|---|
| ヤング率 `E` | 工学値または真全ひずみを入力する場合は必須 | 弾性ひずみの除去 |
| 降伏応力 `σy` | 常に必須 | 塑性域の開始点および硬化則の初期応力 |

ヤング率と降伏応力の単位は応力データと合わせる。内部ではMPaへ変換する。初期版では両値の自動推定を行わない。

### 5.3 入力検証

- CSV以外のファイルは受け付けない。
- 空ファイル、数値データ不足、列割り当て未完了は処理を開始できない。
- `NaN`、無限値、空欄、数値へ変換できない値を含む行は件数と行番号を示す。
- ひずみは昇順に並べ替え、重複ひずみは警告してユーザーに確認可能な状態にする。
- 負の真塑性ひずみは自動補正せず、変換結果の警告対象とする。
- パラメータ数に対してフィッティング点が不足する場合は実行できない。

## 6. データ変換要件

### 6.1 工学応力–工学ひずみ

一様変形を仮定し、次式で変換する。

```text
σ  = s(1 + e)
ε  = ln(1 + e)
εp = ε - σ / E
```

この変換による真応力はネッキング開始前までを有効範囲とする。ネッキング後を正確に補正する機能は初期版の対象外であることを画面に表示する。

### 6.2 真応力–真全ひずみ

次式で真塑性ひずみへ変換する。

```text
εp = ε - σ / E
```

### 6.3 真応力–真塑性ひずみ

応力・ひずみの単位正規化と入力検証のみを行い、値の変換は行わない。

## 7. 硬化則とフィッティング要件

### 7.1 採用する式

独立変数を真塑性ひずみ `εp`、従属変数を真応力 `σ` とする。

| 硬化則 | 採用式 | 自動調整する主パラメータ |
|---|---|---|
| Ludwik | `σ = σy + K εp^n` | `K`, `n` |
| Swift | `σ = K(ε0 + εp)^n`、かつ `σ(0) = σy` | 独立な2パラメータを調整し、残りを算出 |
| Voce | `σ = σy + Q(1 - exp(-b εp))` | `Q`, `b` |

名称や式には文献差があるため、画面上に採用式を常時表示する。`σy` はユーザー入力値で固定し、手動で変更された場合はカーブを再計算する。

### 7.2 自動フィッティング

- 境界付き非線形最小二乗法を使用する。
- データ密度の偏りを抑えるため、真塑性ひずみ区間が均等に寄与する重み付けを既定とする。
- 外れ値を自動削除しない。
- 複数の初期値候補を試し、収束した解のうち目的関数が最小のものを採用する。
- 未収束、パラメータ上限・下限への張り付き、非物理的なカーブを警告する。
- 元データ全点を計算に使用し、グラフ表示用に間引いたデータをフィッティングへ流用しない。

適合度として少なくともRMSE、正規化RMSE、決定係数 `R²`、最大絶対誤差を表示する。

### 7.3 フィッティング範囲

- 始点と終点をグラフ上のハンドルで調整できる。
- ハンドルと数値入力欄を同期する。
- 選択範囲、採用点数、範囲外の点を視覚的に区別する。
- 工学応力入力では、降伏応力に対応する点を始点候補、工学応力最大点をネッキング開始候補として提示する。
- 真応力入力のみではネッキング開始を一意に検出できないため、終点はユーザーが確認・調整する。
- フィッティング時には出力最大塑性ひずみと出力点数を指定させない。

### 7.4 手動調整

- 自動フィッティング結果の各パラメータを数値入力で変更できる。
- 変更時はフィッティングカーブと適合度を即時更新する。
- 自動フィッティング結果へ戻すリセット機能を設ける。
- パラメータの制約範囲は自動・手動で共通とし、範囲外の値は適用しない。

## 8. グラフ要件

次の4段階をそれぞれ確認できるグラフを表示する。

1. アップロードされたデータ
2. 真応力–真塑性ひずみへ変換したデータ
3. 変換データとフィッティング後のカーブ
4. エクスポート対象として再サンプリングしたデータ

各グラフは点と線の表示切り替え、凡例、軸名、単位、ズーム、パン、リセットを備える。フィッティンググラフでは範囲選択を操作できる。

表示点数が設定上限を超える場合は、元データ件数、表示件数、グラフのみ間引くことをメッセージで通知する。間引きにはカーブ形状と極値を保持しやすい方式を採用する。計算、適合度評価、エクスポートには間引き前のデータを使用する。

## 9. エクスポート要件

### 9.1 エクスポート条件

フィッティング完了後の独立したステップで、ユーザーが次を指定する。

- 出力最大真塑性ひずみ
- 出力点数

出力開始点は真塑性ひずみ `0` とし、指定範囲を非等間隔に再サンプリングする。ユーザーが指定した出力総点数を `N`、カーブの総分割数を `N - 1` とし、降伏点付近のカーブ変化を細かく表現するため、総分割数を次の固定比率で配分する。

| 真塑性ひずみ範囲 | 分割数の配分 | 目的 |
|---|---:|---|
| `0 ≤ εp ≤ 0.05` | 50% | 降伏直後の変化を高密度で表現する |
| `0.05 < εp ≤ 0.20` | 35% | 初期から中期の硬化挙動を表現する |
| `0.20 < εp ≤ 出力最大値` | 15% | 大ひずみ域を必要最小限の点で表現する |

- ユーザーが指定する出力点数は、始点と終点を含む20点以上の総点数とする。
- 出力最大値に存在しない区間の分割数は、存在する区間へ同じ比率関係を保って再配分する。
- 分割数の整数化には最大剰余法を使い、合計が必ず `N - 1` になるようにする。
- 区間境界 `0.05`、`0.20` は重複させず、必ず出力点へ含める。ただし出力最大値が境界未満の場合を除く。
- 各区間内では等間隔とする。
- 指定値の変更時はエクスポート対象グラフを更新する。

### 9.2 数値丸め

- 出力するひずみと応力を有効数字6桁へ丸める。
- 小数点以下6桁とは扱わない。
- 非常に大きい値または小さい値では科学表記を許容する。
- 丸め後にひずみが重複する場合は後続の重複点を除外し、警告する。
- 内部計算値や画面上のフィッティング結果は、エクスポート時の丸めで変更しない。

### 9.3 汎用CSV

- 列順は `plastic_strain,true_stress` とする。
- ヘッダーを含むBOM付きUTF-8、CRLFで生成する。
- ひずみ昇順、有限値のみ、重複なしとする。
- ブラウザのダウンロード機能でCSVを保存できる。

### 9.4 LS-DYNA `*DEFINE_CURVE`

- 初期版の対象を `*MAT_PIECEWISE_LINEAR_PLASTICITY`（`*MAT_024`）の `LCSS` 参照向けと明示する。
- X値を真塑性ひずみ、Y値を真応力として `*DEFINE_CURVE` ブロックを生成する。
- `LCID` はユーザーが指定でき、初期値を `1` とする。
- `SIDR=0`、`SFA=1.0`、`SFO=1.0`、`OFFA=0.0`、`OFFO=0.0`、`DATTYP=0`、`LCINT=1001` を初期版の固定値とする。
- LS-DYNAは入力カーブを内部で等間隔に再離散化するため、曲線固有の `LCINT=1001` を明示し、`*CONTROL_SOLUTION` のグローバル値や既定値に依存しない。
- アプリが生成する非等間隔点群と、`LCINT=1001` を模擬した等間隔再離散化後のカーブをプレビューで比較できるようにする。
- 再離散化前後の最大絶対応力差と最大相対応力差を表示する。
- カード項目は10文字幅、X/Yデータは各20文字幅の固定形式を基本とし、桁あふれを避けるため科学表記を許容する。
- プレビュー領域は等幅フォントで表示し、横スクロールを許容する。
- コピーボタンでブロック全体をクリップボードへコピーし、成功・失敗を通知する。
- 初期版では材料カードや `*END` を含めず、既存キーワードデッキへ挿入するカーブ定義だけを生成する。
- 応力単位は材料カードのヤング率・降伏応力と一致させる。LS-DYNA側で一貫した単位系を使うこと、および材料カードの `LCSS` から `LCID` を参照することを注意書きとして表示する。

## 10. 画面フロー

1. CSVアップロード
2. データ種別、列、単位の割り当てと元データ確認
3. ヤング率、降伏応力の入力と真値への変換
4. 硬化則選択、フィッティング範囲設定、自動フィッティング
5. パラメータの確認・手動調整
6. 出力最大真塑性ひずみと出力点数の指定
7. エクスポート対象グラフの確認
8. 汎用CSVダウンロードまたはLS-DYNA `*DEFINE_CURVE` コピー

前段の入力を変更して後段の結果が無効になった場合は、古い結果を表示し続けず、再変換・再フィッティングが必要であることを示す。

## 11. 非機能要件

### 11.1 性能

- CSV解析、フィッティング、再サンプリングでUIを長時間ブロックしない。
- 重い計算はWeb Workerへ分離できる構造にする。
- 表示用点数上限などの閾値は設定モジュールで一元管理する。

### 11.2 セキュリティとプライバシー

- CSVデータをネットワーク送信しない。
- CSV内容をHTMLとして直接描画しない。
- ページ再読み込み時に試験データと計算結果を破棄する。

### 11.3 数値品質

- 内部計算にはJavaScriptの倍精度浮動小数点数を使用する。
- 単位変換、表示丸め、エクスポート丸めを分離する。
- 同じ入力と設定から同じ結果が得られる決定的な計算にする。

## 12. 受け入れ基準

- 3種類の入力形式を選択してCSVを読み込める。
- 工学値と真全ひずみを、入力されたヤング率により真塑性ひずみへ変換できる。
- Ludwik、Swift、Voceの各モデルで範囲を指定して自動フィッティングできる。
- 自動結果のパラメータを変更するとグラフが更新され、結果をリセットできる。
- 大量点群では通知後にグラフだけを間引き、フィッティングは全点を使用する。
- エクスポート工程でのみ最大塑性ひずみと点数を指定できる。
- エクスポートカーブの分割数の50%が `εp=0～0.05`、35%が `0.05～0.20`、15%がそれ以降へ配分される。
- 有効数字6桁の汎用CSVをダウンロードできる。
- 有効数字6桁のLS-DYNA `*DEFINE_CURVE` をプレビューしてコピーできる。
- LS-DYNAプレビューに `LCINT=1001` が出力され、内部再離散化を模擬したカーブとの差を確認できる。
- 処理中にCSVデータがサーバーへ送信されない。
