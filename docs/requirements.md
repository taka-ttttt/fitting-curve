# SSカーブフィッティングアプリ 要件定義書

## 1. 文書情報

- 対象: `frontend` に構築する Next.js アプリケーション
- ステータス: ハイブリッドSSカーブ対応改訂要件
- 処理方式: ブラウザ内で完結し、アップロードデータをサーバーへ送信しない
- 関連計画: [`hybrid-curve-implementation-plan.md`](./hybrid-curve-implementation-plan.md)

## 2. 目的

金属材料の引張試験データを、CAE解析で利用する真応力–真塑性ひずみカーブへ変換する。明確な降伏点がない材料では、0.2%耐力を塑性開始点に置き換えず、比例限度から接続点までは実測挙動を保持し、接続点以降をLudwik、Swift、Voceの各硬化則で外挿したハイブリッドSSカーブを生成する。降伏遷移域は段階的な重みでフィッティングへ含め、接続点の応力を厳密に一致させる。始点条件に対する信頼性はパラメータ変化率ではなく外挿曲線の変動幅で評価する。自動フィッティング後の手動調整、グラフによる確認、汎用CSVのダウンロードおよびLS-DYNA `*DEFINE_CURVE` 形式のコピーを一連の画面で行えるようにする。

## 3. 対象範囲

### 3.1 対象に含むもの

- 1ファイル、1試験カーブのCSVアップロード
- CSV列の割り当て、単位、ひずみ表現の指定
- 工学応力–工学ひずみから真応力–真塑性ひずみへの変換
- 真応力–真全ひずみから真応力–真塑性ひずみへの変換
- 真応力–真塑性ひずみの直接利用
- 真塑性ひずみ残差による比例限度候補の自動検出と手動修正
- 0.2%耐力の算出と参考値表示
- Ludwik、Swift、Voce硬化則への自動フィッティング
- 降伏遷移終了点、フィッティング終点、実測・硬化則接続点の調整
- 降伏遷移域の段階重み付けと始点条件に対する外挿曲線感度の評価
- 実測区間と硬化則外挿区間を連続接続したハイブリッドSSカーブの生成
- フィッティングパラメータの手動調整
- エクスポート条件を指定したカーブの生成とプレビュー
- 汎用CSVのダウンロード
- LS-DYNA `*MAT_024` の `LCSS` 参照向け `*DEFINE_CURVE` テキストのプレビューとクリップボードへのコピー

### 3.2 初期版の対象外

- 荷重–標点間伸び、荷重–クロスヘッド変位の入力
- ネッキング後の断面積変化を考慮した真応力補正
- 温度依存性、ひずみ速度依存性、異方性、損傷・破断モデル
- 除荷・再負荷試験による真の弾性限度の同定、非線形弾性および粘塑性の分離
- 複数試験カーブの平均化や同時フィッティング
- ユーザー認証、サーバー保存、履歴共有
- LS-DYNA材料カード全体の生成および特定材料モデルへの自動接続
- LS-DYNAキーワードファイルのダウンロード

## 4. 用語とデータ定義

| 用語 | 記号 | 定義 |
|---|---:|---|
| 工学応力 | `s` | 初期断面積を基準にした応力 |
| 工学ひずみ | `e` | 初期標点距離を基準にしたひずみ |
| 真応力 | `σ` | 変形中の断面積を基準にした応力 |
| 真全ひずみ | `ε` | 弾性ひずみと塑性ひずみを含む対数ひずみ |
| 真塑性ひずみ | `εp` | 真全ひずみから弾性ひずみを除いた値 |
| 比例限度 | `σ0` | 弾性直線からの継続的な逸脱を真塑性ひずみ残差で検出し、塑性曲線の始点とする応力 |
| 0.2%耐力 | `Rp0.2` | 0.2%オフセット直線と入力曲線の交点で得る参考材料特性値。塑性開始点とは扱わない |
| 降伏遷移終了点 | `εtr` | 比例限度から始まる降伏遷移域を終了し、フィッティング重みを1とする点 |
| フィッティング終点 | `εfit,end` | 実測残差を目的関数へ使用する最後の点。接続点以前に置く |
| 接続点 | `(εj, σj)` | 実測区間を終了し、実測接続応力 `σj` の拘束を満たした硬化則区間を開始する点 |
| ハイブリッドSSカーブ | - | 接続点までは実測点群の補間、接続点以降は硬化則で構成する真応力–真塑性ひずみカーブ |
| SSカーブ | - | 本書では応力–ひずみカーブを指す |

内部計算では応力をMPa、ひずみを無次元量に正規化する。画面入力時には応力単位と、ひずみが無次元量か `%` かをユーザーが選択できるようにする。

## 5. 入力要件

### 5.1 対応するCSVデータ種別

ユーザーはアップロード時に次のいずれかを選択する。

1. 工学応力–工学ひずみ
2. 真応力–真全ひずみ
3. 真応力–真塑性ひずみ

CSVにはヘッダー行を許容し、プレビュー後にX列とY列をユーザーが割り当てる。列名に依存した自動確定は行わず、候補の自動選択に留める。

### 5.2 材料物性

ユーザーは次の値を入力または確認する。

| 項目 | 必須条件 | 用途 |
|---|---|---|
| ヤング率 `E` | 工学値または真全ひずみを入力する場合は必須 | 弾性ひずみの除去、比例限度候補と0.2%耐力の算出 |
| 比例限度判定しきい値 | 工学値または真全ひずみを入力する場合に使用 | 真塑性ひずみ残差による自動検出。初期値は `0.0001` |
| 比例限度候補 | 自動検出後にユーザー確認が必須 | 塑性曲線の真塑性ひずみ `0` と初期応力 `σ0` の基準 |

ヤング率の単位は応力データと合わせ、内部ではMPaへ変換する。ヤング率は自動推定せず、ユーザー入力値を使用する。比例限度候補は自動検出するが、試験機コンプライアンスやノイズの影響を受けるため、グラフ上での確認・手動修正を必須とする。真応力–真塑性ひずみを直接入力する場合は、最初の採用点を `εp=0` とし、その応力を `σ0` とする。

### 5.3 入力検証

- CSV以外のファイルは受け付けない。
- 空ファイル、数値データ不足、列割り当て未完了は処理を開始できない。
- `NaN`、無限値、空欄、数値へ変換できない値を含む行は件数と行番号を示す。
- ひずみは昇順に並べ替え、重複ひずみは警告してユーザーに確認可能な状態にする。
- 比例限度候補より後に負の相対真塑性ひずみが残る場合は警告し、ハイブリッド曲線を生成できない。
- 降伏遷移終了点、フィッティング終点、接続点の順序が不正な場合はフィッティングを実行できない。
- パラメータ数に対してフィッティング点が不足する場合は実行できない。

## 6. データ変換要件

### 6.1 工学応力–工学ひずみ

一様変形を仮定し、次式で変換する。

```text
σ  = s(1 + e)
ε  = ln(1 + e)
εp_raw = ε - σ / E
```

この変換による真応力はネッキング開始前までを有効範囲とする。ネッキング後を正確に補正する機能は初期版の対象外であることを画面に表示する。

### 6.2 真応力–真全ひずみ

次式で真塑性ひずみへ変換する。

```text
εp_raw = ε - σ / E
```

### 6.3 真応力–真塑性ひずみ

応力・ひずみの単位正規化と入力検証のみを行い、値の変換は行わない。比例限度の自動検出と0.2%耐力の算出は行わず、最初の採用点が `εp=0` であることを要求する。

### 6.4 比例限度候補と0.2%耐力

工学応力–工学ひずみまたは真応力–真全ひずみの入力では、次の手順で比例限度候補を求める。

1. `εp_raw = ε - σ/E` を全点について計算する。
2. 初期値 `0.0001` の判定しきい値以上となる状態が3点連続した最初の点を検出する。
3. 直前点と最初の継続超過点の間を補間して比例限度候補を作る。
4. 比例限度候補をハイブリッド曲線の `εp=0`、`σ=σ0` とする。
5. 候補以後の `εp_raw` から候補点の `εp_raw` を差し引き、比例限度以後の相対真塑性ひずみへ正規化する。

- 判定しきい値と連続点数は設定モジュールで一元管理し、画面に使用値を表示する。
- 自動検出できない場合は理由を表示し、ユーザーが入力曲線上の点を比例限度として指定できるようにする。
- 自動検出結果は確定値として扱わず、ユーザーがグラフ上または数値入力で修正できるようにする。
- 比例限度より前の点は塑性カーブ、フィッティング、エクスポートに使用しない。
- 0.2%耐力は入力曲線と `σ=E(ε-0.002)` の交点から別途算出し、比例限度候補と同じグラフに参考マーカーとして表示する。
- 0.2%耐力を真塑性ひずみ `0` へ移動したり、ハイブリッド曲線の始点として使用したりしない。
- 真応力–真全ひずみ入力から0.2%耐力を求める場合は、一様変形の範囲で工学応力–工学ひずみへ逆変換して判定する。
- 比例限度の自動検出は単調引張に対する工学的近似であり、除荷試験で確認した弾性限度と同一とは保証しない旨を表示する。

## 7. 硬化則とフィッティング要件

### 7.1 採用する式

独立変数を比例限度からの相対真塑性ひずみ `εp`、従属変数を真応力 `σ` とする。比例限度応力を `σ0` とし、フィッティングに使用する基底関数 `f(εp)` を次のとおり定義する。

| 硬化則 | 採用式 | 独立に自動調整するパラメータ |
|---|---|---|
| Ludwik | `f(εp) = σ0 + K εp^n` | `n`。`K` は接続応力から算出 |
| Swift | `f(εp) = K(ε0 + εp)^n`、かつ `f(0) = σ0` | `ε0`。`n` と `K` は接続応力から算出 |
| Voce | `f(εp) = σ0 + Q(1 - exp(-b εp))` | `b`。`Q` は接続応力から算出 |

名称や式には文献差があるため、画面上に基底関数と後述する接続制約を常時表示する。`σ0` は確認済みの比例限度候補から決まり、比例限度を変更した場合は変換、フィッティング、ハイブリッド曲線、エクスポート結果を無効化する。

### 7.2 自動フィッティング

- 接続後に硬化則全体を上下移動する方式を廃止し、基底関数そのものが接続点 `(εj, σj)` を通るようにパラメータ間の拘束を課す。
- Ludwikは `n`、Swiftは `ε0`、Voceは `b` を独立な形状パラメータとし、残りのパラメータを `f(εj)=σj` から算出する。
- LudwikとSwiftは `0<n<1`、Voceは `Q>0` かつ `b>0` を必須とする。
- データ密度の偏りを抑えるため、真塑性ひずみ区間幅を積分重みとして使用する。
- 比例限度から `εtr` までの降伏遷移域は完全除外せず、小さい重みから1まで連続的に増加させる。`εtr=0` の場合は全点の遷移重みを1とする。
- 遷移重みは `0≤εp<εtr` で `w=0.1+0.9{1−cos(πεp/εtr)}/2`、`εp≥εtr` で `w=1` とする。
- 接続点が工学応力最大点であり、かつ `E>σj` の場合は、Considère条件から目標接線係数 `Hj=σjE/(E-σj)` を算出し、目的関数へ接線誤差ペナルティとして加える。
- 接線誤差ペナルティの初期係数は `0.25` とし、接続点を工学応力最大点から動かした場合は適用しない。
- 外れ値を自動削除せず、元データ全点を使用する。グラフ表示用に間引いたデータをフィッティングへ流用しない。
- 非収束、有効解なし、パラメータ境界への張り付き、非物理的なカーブを警告する。

適合度としてRMSE、正規化RMSE、決定係数 `R²`、最大絶対誤差を表示する。加えて、接続点の局所回帰接線、Considère目標接線、モデル接線および目標接線に対する相対誤差を表示する。

### 7.3 フィッティング範囲と始点感度

- 降伏遷移終了点 `εtr`、フィッティング終点 `εfit,end`、接続点 `εj` を独立して指定できる。
- 残差評価には `0≤εp≤εfit,end` の実測点を使用し、`0≤εp<εtr` は段階重み、`εtr≤εp≤εfit,end` は重み1とする。
- `0≤εtr<εfit,end≤εj`、かつ接続点が変換済み実測範囲内にあることを必須とする。
- 工学応力入力では、0.2%耐力に対応する塑性ひずみを `εtr` の初期候補、工学応力最大点を `εfit,end` と `εj` の初期候補として提示する。
- 真応力入力のみではネッキング開始を一意に検出できないため、`εfit,end` と `εj` はユーザーが確認・調整する。
- 始点感度は、点間隔と接続ひずみに基づく複数の `εtr` 候補で再フィットして評価する。
- 感度計算では、フィット点の塑性ひずみ間隔中央値を `Δε` とし、変動量を `δ=max(2Δε, 0.01εj)` とする。`εtr−2δ`、`εtr−δ`、`εtr`、`εtr+δ`、`εtr+2δ` を有効範囲へ制限して候補とする。
- 感度判定にパラメータ変化率を使用しない。接続点より先の共通評価ひずみにおける予測応力の最小値、最大値および相対幅を使用する。
- 共通評価ひずみは `εeval=εj+max(εj, 0.1)` とする。
- 相対幅2%以下を「安定」、2%超5%以下を「注意」、5%超を「不安定」の初期基準とする。
- フィッティング時にはユーザーの出力最大塑性ひずみと出力点数を参照しない。

### 7.4 ハイブリッドSSカーブ

接続点の実測応力を `σj`、`f(εj)=σj` を満たす選択硬化則を `f` とし、ハイブリッドSSカーブを次式で構成する。

```text
σhybrid(εp) = σexp(εp)                         (0 ≤ εp ≤ εj)
σhybrid(εp) = f(εp)                            (εp > εj)
```

- 実測区間の `σexp` は、表示用に間引く前の変換済み実測点を線形補間する。
- パラメータ拘束により `σhybrid(εj)=σj` を厳密に満たし、任意の上下移動による応力ジャンプの除去は行わない。
- 接続点近傍の複数実測点による局所回帰接線、Considère目標接線、接続点直後の硬化則接線を算出して表示する。
- 接線係数の厳密一致は必須条件としないが、負値、非有限値または符号反転がある場合はエクスポートを禁止する。目標接線との相対誤差は警告として表示する。
- 実測区間と硬化則区間をグラフ上で異なる線種または色にし、接続点を明示する。
- 接続点以降は実測点の有無にかかわらず硬化則区間として扱うことを明示し、実測最大ひずみを超える範囲は外挿として追加で区別する。
- 元の実測点群は変更せず、ハイブリッド曲線を独立した派生データとして保持する。

### 7.5 手動調整

- 自動フィッティング結果の独立形状パラメータを数値入力で変更できる。
- 変更時はフィッティングカーブと適合度を即時更新する。
- 自動フィッティング結果へ戻すリセット機能を設ける。
- パラメータの制約範囲は自動・手動で共通とし、範囲外の値は適用しない。
- 手動調整では各モデルの独立形状パラメータだけを編集可能とし、接続応力を満たす従属パラメータを再計算する。
- パラメータ、降伏遷移終了点、フィッティング終点または接続点を変更した場合は、適合度、接線係数およびエクスポート結果を再計算する。

## 8. グラフ要件

次の4段階をそれぞれ確認できるグラフを表示する。

1. アップロードされたデータ
2. 真応力–真塑性ひずみへ変換したデータ、比例限度候補、0.2%耐力
3. 変換データ、フィッティング範囲、接続点、実測区間および接続制約後の硬化則区間
4. エクスポート対象としてハイブリッドSSカーブを再サンプリングしたデータ

各グラフは点と線の表示切り替え、凡例、軸名、単位、ズーム、パン、リセットを備える。フィッティンググラフでは範囲選択を操作できる。

表示点数が設定上限を超える場合は、元データ件数、表示件数、グラフのみ間引くことをメッセージで通知する。間引きにはカーブ形状と極値を保持しやすい方式を採用する。計算、適合度評価、エクスポートには間引き前のデータを使用する。

## 9. エクスポート要件

### 9.1 エクスポート条件

フィッティング完了後の独立したステップで、ユーザーが次を指定する。

- 出力最大真塑性ひずみ
- 出力点数

出力開始点は真塑性ひずみ `0` とし、ハイブリッドSSカーブを指定範囲で非等間隔に再サンプリングする。`εp≤εj` の応力は実測点群の線形補間、`εp>εj` の応力は接続制約後の硬化則から求める。ユーザーが指定した出力総点数を `N`、カーブの総分割数を `N - 1` とし、降伏点付近のカーブ変化を細かく表現するため、総分割数を次の固定比率で配分する。

| 真塑性ひずみ範囲 | 分割数の配分 | 目的 |
|---|---:|---|
| `0 ≤ εp ≤ 0.05` | 50% | 降伏直後の変化を高密度で表現する |
| `0.05 < εp ≤ 0.20` | 35% | 初期から中期の硬化挙動を表現する |
| `0.20 < εp ≤ 出力最大値` | 15% | 大ひずみ域を必要最小限の点で表現する |

- ユーザーが指定する出力点数は、始点と終点を含む20点以上の総点数とする。
- 出力最大値に存在しない区間の分割数は、存在する区間へ同じ比率関係を保って再配分する。
- 分割数の整数化には最大剰余法を使い、合計が必ず `N - 1` になるようにする。
- 区間境界 `0.05`、`0.20` は重複させず、必ず出力点へ含める。ただし出力最大値が境界未満の場合を除く。
- 比例限度の始点 `0`、接続点 `εj`、出力最大値は必ず出力点へ含める。接続点が区間境界と一致する場合は重複させない。
- 必須点を先に確保し、残りの点数を固定比率と最大剰余法で配分して、出力点数を必ず `N` に保つ。
- 各区間内では等間隔とする。
- 指定値の変更時はエクスポート対象グラフを更新する。
- 出力最大値が接続点を超える場合は、硬化則による外挿範囲をグラフで区別して警告する。

### 9.2 数値丸め

- 出力するひずみと応力を有効数字6桁へ丸める。
- 小数点以下6桁とは扱わない。
- 非常に大きい値または小さい値では科学表記を許容する。
- 丸め後にひずみが重複する場合は後続の重複点を除外し、警告する。
- 内部計算値や画面上のフィッティング結果は、エクスポート時の丸めで変更しない。

### 9.3 汎用CSV

- 列順は `plastic_strain,true_stress` とする。
- ヘッダーを含むBOM付きUTF-8、CRLFで生成する。
- ひずみ昇順、有限値のみ、重複なしとする。
- ブラウザのダウンロード機能でCSVを保存できる。

### 9.4 LS-DYNA `*DEFINE_CURVE`

- 初期版の対象を `*MAT_PIECEWISE_LINEAR_PLASTICITY`（`*MAT_024`）の `LCSS` 参照向けと明示する。
- X値を真塑性ひずみ、Y値を真応力として `*DEFINE_CURVE` ブロックを生成する。
- `LCID` はユーザーが指定でき、初期値を `1` とする。
- `SIDR=0`、`SFA=1.0`、`SFO=1.0`、`OFFA=0.0`、`OFFO=0.0`、`DATTYP=0`、`LCINT=1001` を初期版の固定値とする。
- LS-DYNAは入力カーブを内部で等間隔に再離散化するため、曲線固有の `LCINT=1001` を明示し、`*CONTROL_SOLUTION` のグローバル値や既定値に依存しない。
- アプリが生成する非等間隔点群と、`LCINT=1001` を模擬した等間隔再離散化後のカーブをプレビューで比較できるようにする。
- 再離散化前後の最大絶対応力差と最大相対応力差を表示する。
- カード項目は10文字幅、X/Yデータは各20文字幅の固定形式を基本とし、桁あふれを避けるため科学表記を許容する。
- プレビュー領域は等幅フォントで表示し、横スクロールを許容する。
- コピーボタンでブロック全体をクリップボードへコピーし、成功・失敗を通知する。
- 初期版では材料カードや `*END` を含めず、既存キーワードデッキへ挿入するカーブ定義だけを生成する。
- 応力単位は入力データ、ヤング率および材料カードと一致させる。LS-DYNA側で一貫した単位系を使うこと、および材料カードの `LCSS` から `LCID` を参照することを注意書きとして表示する。

## 10. 画面フロー

1. CSVアップロード
2. データ種別、列、単位の割り当てと元データ確認
3. ヤング率入力、真値への変換、比例限度候補と0.2%耐力の算出
4. 比例限度候補の確認・手動修正
5. 硬化則選択、降伏遷移終了点、フィッティング終点、接続点の設定、自動フィッティング
6. ハイブリッドSSカーブ、適合度、始点感度、接続部の応力・接線係数の確認
7. パラメータの確認・手動調整
8. 出力最大真塑性ひずみと出力点数の指定
9. 実測区間と外挿区間を区別したエクスポート対象グラフの確認
10. 汎用CSVダウンロードまたはLS-DYNA `*DEFINE_CURVE` コピー

前段の入力を変更して後段の結果が無効になった場合は、古い結果を表示し続けず、再変換・再フィッティングが必要であることを示す。

## 11. 非機能要件

### 11.1 性能

- CSV解析、フィッティング、再サンプリングでUIを長時間ブロックしない。
- 重い計算はWeb Workerへ分離できる構造にする。
- 表示用点数上限などの閾値は設定モジュールで一元管理する。

### 11.2 セキュリティとプライバシー

- CSVデータをネットワーク送信しない。
- CSV内容をHTMLとして直接描画しない。
- ページ再読み込み時に試験データと計算結果を破棄する。

### 11.3 数値品質

- 内部計算にはJavaScriptの倍精度浮動小数点数を使用する。
- 単位変換、表示丸め、エクスポート丸めを分離する。
- 同じ入力と設定から同じ結果が得られる決定的な計算にする。
- 比例限度判定しきい値、連続点数、接続判定の許容誤差を設定モジュールで一元管理する。

## 12. 受け入れ基準

- 3種類の入力形式を選択してCSVを読み込める。
- 工学値と真全ひずみを、入力されたヤング率により真塑性ひずみへ変換できる。
- 工学値または真全ひずみから、真塑性ひずみ残差が `0.0001` 以上となる状態が3点連続する条件で比例限度候補を検出できる。
- 比例限度候補をグラフと数値入力で修正でき、修正後の点が真塑性ひずみ `0` になる。
- 0.2%耐力を参考値として表示し、塑性曲線の始点には使用しない。
- Ludwik、Swift、Voceの各モデルで降伏遷移終了点、フィッティング終点、接続点を指定して自動フィッティングできる。
- 降伏遷移域の重みが連続的に変化し、遷移終了点を小さく動かしても採用点が不連続に切り替わらない。
- 接続点までは表示用間引き前の実測点群、接続点以降は接続応力拘束を満たす硬化則となるハイブリッドSSカーブを生成できる。
- 接続点で実測応力と硬化則応力が数値許容誤差内で一致する。
- 局所回帰接線、Considère目標接線、モデル接線と相対誤差を表示し、負値、非有限値または符号反転時はエクスポートできない。
- 複数の遷移終了点に対する外挿応力の最小値、最大値、相対幅と「安定・注意・不安定」を表示できる。
- 自動結果のパラメータを変更するとグラフが更新され、結果をリセットできる。
- 大量点群では通知後にグラフだけを間引き、フィッティングは全点を使用する。
- エクスポート工程でのみ最大塑性ひずみと点数を指定できる。
- エクスポート結果に真塑性ひずみ `0`、接続点、出力最大値が各1回だけ含まれ、総点数が指定値と一致する。
- エクスポート結果が接続点までは実測補間値、接続点以降は硬化則の値から生成される。
- エクスポートカーブの分割数の50%が `εp=0～0.05`、35%が `0.05～0.20`、15%がそれ以降へ配分される。
- 有効数字6桁の汎用CSVをダウンロードできる。
- 有効数字6桁のLS-DYNA `*DEFINE_CURVE` をプレビューしてコピーできる。
- LS-DYNAプレビューに `LCINT=1001` が出力され、内部再離散化を模擬したカーブとの差を確認できる。
- 処理中にCSVデータがサーバーへ送信されない。
