# ハイブリッドSSカーブ対応 実装計画

## 1. なぜやるか

0.2%耐力を塑性開始点とする変換では、明確な降伏点を持たない材料の降伏近傍を十分に再現できない。また、フィッティング終点で硬化則を上下移動する方式では、始点を少し変えただけでSwiftなどが識別不能な近直線解へ移り、パラメータの意味が失われる。比例限度から接続点までは実測挙動を保持し、降伏遷移域を段階重みでフィッティングへ含め、接続応力を満たす標準硬化則だけを外挿に使用する。始点条件の信頼性はパラメータ変化率ではなく外挿曲線の変動幅で評価する。

## 3. どう実装するか

1. **データ型と定数を先に確定する**
   入力形式を工学応力–工学ひずみ、真応力–真全ひずみ、真応力–真塑性ひずみの3種類として明示する。比例限度判定しきい値を `1e-4`、連続点数を `3` として設定モジュールへ置き、比例限度候補、確認状態、0.2%耐力、接続点、接線係数を型で分離する。

2. **変換処理を真塑性ひずみの定義に合わせて修正する**
   工学値を真値へ変換した後、各点を `εp_raw=ε-σ/E` で処理する。現在の「指定降伏点の全ひずみを一律に差し引く」処理は廃止する。`εp_raw` がしきい値以上となる状態が3点連続する最初の区間から比例限度候補を補間し、候補点を `εp=0` として以後の点を相対真塑性ひずみに変換する。0.2%耐力は別の派生値として算出し、塑性ひずみ原点には使用しない。

3. **比例限度の確認工程を状態管理へ追加する**
   自動候補を未確認状態で保持し、ユーザーが確定するまでフィッティングへ進めないようにする。候補はグラフ選択または数値入力で修正可能にし、修正時は変換済み塑性点群を再生成する。CSV、列、単位、ヤング率、比例限度を変更した場合はフィット、ハイブリッド曲線、エクスポートを無効化する。

4. **接続応力拘束を純粋関数として実装する**
   `hybrid-curve.ts` に実測点の線形補間、各硬化則の接続応力拘束、局所回帰接線、Considère目標接線を実装する。Ludwikは `n`、Swiftは `ε0`、Voceは `b` を独立形状パラメータとし、残りを `f(εj)=σj` から導出する。`εp≤εj` は実測補間、`εp>εj` は上下移動していない標準硬化則を返す単一評価関数をグラフ、適合度、エクスポートで共有する。

5. **段階重み付きフィットと始点感度を実装する**
   降伏遷移終了点 `εtr` までは小さい重みから1へ連続的に増加させ、`εtr` 以降の重みを1とする。点密度の影響は真塑性ひずみ区間幅で補正する。接続点がUTSの場合はConsidère接線誤差を目的関数へ加える。`εtr` を点間隔と接続ひずみに基づいて前後へ動かした複数フィットを実行し、共通評価ひずみの外挿応力幅から「安定・注意・不安定」を判定する。Worker要求へ `E`、`εfit,end`、`εj` を追加する。

6. **画面を実測保持と外挿不確かさの確認に合わせて変更する**
   変換工程では比例限度候補、判定条件、0.2%耐力を同時表示する。フィット工程では「降伏遷移終了点」「フィッティング終点」「実測・硬化則接続点」を分離する。モデルごとに局所回帰接線、Considère目標接線、モデル接線、接線誤差、感度評価ひずみの応力幅を表示する。手動調整は独立形状パラメータだけを許可し、従属パラメータは接続応力拘束から再計算する。

7. **エクスポートをハイブリッド曲線へ切り替える**
   `generateExport` に変換済み実測点、接続点、モデルパラメータを渡し、共有評価関数から応力を生成する。`0`、`εj`、出力最大値、および有効な区間境界を必須点として先に確保し、残りを既定比率と最大剰余法で配分して総点数を厳密に `N` にする。CSV、LS-DYNA、LCINTプレビューは同一のハイブリッド点群を使用する。

8. **テストを更新して全体回帰を確認する**
   合成データで比例限度検出、手動修正、0.2%耐力との分離、3硬化則の接続応力拘束、遷移重みの連続性、Considère接線、曲線感度判定、接続点を含む点数配分を検証する。既存の状態無効化テストとE2Eを新しい工程へ更新し、最後にLint、型チェック、全単体テスト、E2E、production buildを実行する。

## 4. 検証方法

- [ ] 工学値と真全ひずみ入力で `εp_raw=ε-σ/E` が既知解と一致する
- [ ] `εp_raw≥1e-4` が3点連続する条件から比例限度候補を決定的に検出する
- [ ] しきい値未満の一時的なノイズおよび1～2点だけの超過を比例限度として採用しない
- [ ] 比例限度候補を修正すると、修正点が `εp=0` となり後段結果が無効化される
- [ ] 0.2%耐力は算出・表示されるが、塑性点群の原点と硬化則の初期応力を変更しない
- [ ] 真応力–真塑性ひずみ直接入力では先頭点 `εp=0` を使用し、自動検出を行わない
- [ ] Ludwik、Swift、Voceの標準モデルが任意の上下移動なしで接続点の実測応力と一致する
- [ ] 遷移終了点の前後で重みが連続し、点の採否が不連続に切り替わらない
- [ ] 接続点の局所回帰接線、Considère目標接線、モデル接線が既知解と一致する
- [ ] 始点候補ごとの外挿応力幅から2%・5%境界の感度区分を決定できる
- [ ] 負値、非有限値または符号反転の接線診断時にエクスポートできない
- [ ] フィッティング指標が接続応力拘束モデルとフィット終点までの全実測点から算出される
- [ ] 表示用間引きを変更しても比例限度、フィット、ハイブリッド曲線、出力値が変化しない
- [ ] 出力点に `0`、接続点、出力最大値、適用対象の区間境界が重複なく含まれる
- [ ] 必須点を追加しても出力総点数が指定した `N` と一致する
- [ ] CSVとLS-DYNAの接続点前は実測補間値、接続点後は硬化則値になる
- [ ] CSVがBOM付きUTF-8・CRLF、数値が有効数字6桁で生成される
- [ ] `LCINT=1001` の再離散化比較がハイブリッド点群を対象に行われる
- [ ] `npm --prefix frontend run lint` が成功する
- [ ] `npm --prefix frontend run typecheck` が成功する
- [ ] `npm --prefix frontend test` が全件成功する
- [ ] `npm --prefix frontend run test:e2e` が全件成功する
- [ ] `npm --prefix frontend run build` が成功する

## 5. リスク・注意点

- 比例限度は試験機コンプライアンス、ヤング率の誤差、ゼロ点ずれ、点密度に敏感である。自動候補を確定値にせず、元曲線と残差を見ながらユーザーが確認できるようにする。
- 弾性直線からの逸脱は必ずしも不可逆塑性だけを意味しない。非線形弾性や粘塑性が支配的な材料へ本手法を無条件に適用しない。
- しきい値 `1e-4` と連続3点は初期既定値であり、普遍的な材料定数ではない。コードへ散在させず、将来の設定変更に備える。
- 実測点に負の加工硬化や大きなノイズがある場合、接続点左側の接線係数が不安定になる。元データを黙って平滑化・単調化せず、診断を表示して接続点の見直しを促す。
- 応力は接続点で連続になるが、接線係数は必ずしも一致しない。不透明な自動ブレンドを追加せず、局所回帰値、Considère値、モデル値を並べて表示する。
- 工学値からの真値変換はネッキング後に成立しない。工学応力最大点を既定の接続候補とし、それより後の未補正データをフィッティングへ混入させない。
- パラメータが大きく変化しても観測範囲・外挿範囲の曲線がほぼ同じ場合があるため、パラメータ変化率を安定性指標に使用しない。
- UTSまでのデータだけでは遠方の大ひずみ挙動を一意に決められない。感度幅が大きい場合は単一モデルを正解として扱わない。
- 接続点を必須出力点にすると既存の固定比率配分が変化する。総点数、境界重複、極端に少ない区間点数を境界値テストで固定する。
- 単調引張曲線への適合度が向上しても、除荷・再負荷、繰返し、異方性、ひずみ速度依存性の予測精度は保証しない。
